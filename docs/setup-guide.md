# Setup Guide

This guide explains how to configure and run the AI-Powered Social Media Automation workflow in Make.com.

## Prerequisites

Before importing the workflow, you will need accounts for:

- Make.com
- Google Sheets
- OpenAI
- Perplexity AI
- Leonardo AI
- Facebook
- LinkedIn

You will also need API access for:

- OpenAI
- Perplexity AI
- Leonardo AI

## 1. Prepare Google Sheets

Create a Google Sheet with the following columns in Row 1:

| Column | Header |
|---|---|
| A | Status |
| B | Topic or Text |
| C | URL |
| D | Summary |
| E | Facebook Post |
| F | LinkedIn Post |
| G | Instagram Post |
| H | Image Prompt |
| I | Image URL |

Example:

| Status | Topic or Text | URL |
|---|---|---|
| READY | Artificial Intelligence careers | |

The remaining columns are populated automatically by the workflow.

## 2. Import the Make.com Blueprint

Download:

`blueprint/social-media-automation-sanitized.json`

from this repository.

In Make.com:

1. Create a new scenario.
2. Open the scenario editor.
3. Select the option to import a blueprint.
4. Upload the JSON blueprint from this repository.
5. Save the scenario.

The public blueprint does not contain personal authentication credentials.

You must configure your own connections after importing it.

## 3. Configure Google Sheets

Open the Google Sheets modules.

Connect your own Google account.

Select the spreadsheet you created earlier.

Select the correct worksheet.

Make sure the first row contains the expected column headers.

The first Google Sheets module watches for new rows.

The later Google Sheets module writes the AI-generated results back to the same row.

## 4. Configure Perplexity AI

Open the Perplexity AI module.

Create or select your own Perplexity connection using your API credentials.

The workflow uses Perplexity to research and summarize the topic supplied through Google Sheets.

The summary becomes the source material for the following AI modules.

## 5. Configure OpenAI

Connect the OpenAI modules to your own OpenAI account.

The workflow contains separate OpenAI tasks for:

1. Facebook post generation
2. LinkedIn post generation
3. Image prompt generation

Each module receives the research summary generated by Perplexity AI.

## 6. Configure Leonardo AI

Connect the Leonardo AI module using your own Leonardo API credentials.

The workflow sends the AI-generated image prompt to Leonardo AI.

Leonardo generates the social media image and returns an image URL.

## 7. Configure Facebook

Open the Facebook Pages module.

Connect your Facebook account.

Select the Facebook Page where the automation should publish.

The module uses:

- The Facebook post generated by OpenAI
- The image generated by Leonardo AI

Do not leave the placeholder Facebook Page configuration unchanged.

## 8. Configure LinkedIn

Open the LinkedIn module.

Connect your own LinkedIn account.

This workflow is configured for publishing to a personal LinkedIn profile.

The LinkedIn route contains an HTTP module before the LinkedIn publishing module.

The HTTP module downloads the Leonardo-generated image as a file.

The LinkedIn module then uploads that downloaded file together with the LinkedIn post generated by OpenAI.

## 9. Review the Google Sheets Update Module

Confirm that the final Google Sheets update module maps the following values:

- Status → `DONE`
- Topic or Text → original Google Sheets topic
- URL → original source URL
- Summary → Perplexity research summary
- Facebook Post → Facebook OpenAI result
- LinkedIn Post → LinkedIn OpenAI result
- Image Prompt → OpenAI image prompt
- Image URL → Leonardo AI image URL

The Instagram column is currently reserved for future development.

## 10. Test the Workflow

Before enabling automatic execution:

1. Add a test row to Google Sheets.
2. Enter a technology topic.
3. Run the Make.com scenario manually.
4. Confirm that Perplexity generates research.
5. Confirm that OpenAI generates the social media posts.
6. Confirm that Leonardo generates an image.
7. Confirm that Google Sheets is updated.
8. Confirm that Facebook publishes successfully.
9. Confirm that LinkedIn publishes successfully.

Always test with non-sensitive content before enabling scheduled automation.
